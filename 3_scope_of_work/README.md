# 3_scope_of_work

Este documento define el alcance, objetivos y metodología del proyecto de análisis de solicitudes, entregas y adquisiciones de medicamentos en instituciones públicas de salud de México.

Se establecen las preguntas de negocio, fuentes de datos, métricas clave, periodos de análisis y entregables esperados para garantizar un enfoque estructurado y orientado a la toma de decisiones basada en datos.

## Objetivos

- Analizar la distribución de medicamentos por tipo de procedimiento.
- Identificar patrones temporales de demanda y entrega.
- Detectar oportunidades potenciales de ahorro en adquisiciones.
- Evaluar la distribución geográfica de medicamentos entre entidades federativas.

## Entregables

- Bases de datos limpias y preparadas para análisis.
- Dashboard interactivo en Tableau.
- Reporte ejecutivo con hallazgos y recomendaciones.
- Código reproducible en R.
